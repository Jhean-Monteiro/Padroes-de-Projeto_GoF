# GoF - Padrões de Projeto em C++

Trabalho de Processo de Desenvolvimento de Software: implementação e estudo dos 23 padrões de projeto do Gang of Four (GoF) em C++.

## Estrutura
- `01-criacionais/`
- `02-estruturais/`
- `03-comportamentais/`

Cada padrão possui seu próprio diretório com código-fonte e um README explicando intenção, problema resolvido e exemplo de uso.
